## Data and storage

LightHub Dev does not ask for personal data. Your browser stores your theme preference and reading progress in localStorage. You can clear this data in your browser settings.

## External services

The code runner loads modules from [esm.sh](https://esm.sh), which receives your IP address when handling the request. The site is hosted on Vercel and GitHub Pages; these providers may log visitors' IP addresses.

## Cookies and contact

On Vercel, the site measures the number of visits with Vercel Web Analytics, without cookies or identifying people: it uses aggregated data and does not use persistent fingerprinting. This analytics tool is not included on GitHub Pages. If you have a question, you can open an issue on [GitHub](https://github.com/PowerOfMind/lighthub-dev/issues).
