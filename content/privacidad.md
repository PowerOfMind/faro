## Datos y almacenamiento

LightHub Dev no solicita datos personales. El navegador guarda en localStorage la preferencia de tema y el progreso de lectura. Puedes borrar estos datos desde la configuración del navegador.

## Servicios externos

El ejecutor de código carga módulos desde [esm.sh](https://esm.sh), que recibe tu dirección IP al atender la solicitud. El sitio se aloja en Vercel y GitHub Pages; estos proveedores pueden registrar la dirección IP de las visitas.

## Cookies y contacto

En Vercel, el sitio mide el número de visitas con Vercel Web Analytics, sin cookies ni identificación de personas: utiliza datos agregados y no hace fingerprinting persistente. En GitHub Pages no se incluye esta analítica. Si tienes alguna pregunta, puedes abrir una incidencia en [GitHub](https://github.com/PowerOfMind/lighthub-dev/issues).
